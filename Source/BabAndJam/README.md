# bab and jam (RimWorld 1.6)

상단 식민지 주민 초상화의 아래쪽에 두 개의 상태 막대를 표시합니다.

- 주황색: 허기(음식 필요도)
- 파란색: 수면(휴식 필요도)

게이지는 초상화 박스 내부 하단에 표시됩니다. 소집 중인 주민의 허기가 설정값(기본 30%) 미만이고 인벤토리에 먹을 수 있는 식량이 있으면, 보존 식량 아이콘의 `휴대 식량 섭취` 명령이 `해제` 명령 왼쪽에 표시됩니다. 이 명령은 기본 `Ingest` 작업을 시작하므로, 일반 식사처럼 섭취 시간이 지나야 식량 한 개가 소모됩니다.

## 설정

모드 설정 화면에서 다음을 변경할 수 있습니다.

- 허기·수면 게이지 표시 켜기/끄기, 표시 위치 선택: 하단·사이드·사이드 외부(왼쪽 허기 / 오른쪽 수면), 수치 갱신 주기 선택: 500/1000/2000/3000ms (기본 1000ms)
- 휴대 식량 섭취 명령 켜기/끄기
- 식사 명령 표시 허기 기준: 10~90% (기본 30%)
- 강제 수면 명령 켜기/끄기
- 소집 중 약물 효과 표시 켜기/끄기

## 빌드

1. `Source/NeedsOnColonistBar/NeedsOnColonistBar.csproj`에서 `RimWorldDir` 및 `HarmonyDir`을 실제 설치 경로로 바꿉니다. Harmony는 Steam Workshop ID `2009463077`입니다.
2. Visual Studio에서 프로젝트를 빌드합니다.
3. 생성된 `1.6/Assemblies/NeedsOnColonistBar.dll`을 포함한 이 폴더를 RimWorld의 `Mods` 폴더에 넣고 모드 목록에서 활성화합니다.

Harmony가 선행 모드로 등록되어 있습니다. 기본 `ColonistBarColonistDrawer.DrawColonist`가 초상화를 그린 직후에만 막대를 추가하므로, 저장 파일에는 영향을 주지 않습니다.
